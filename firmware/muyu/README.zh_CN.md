# Passport 多应用底座 0.6.0

常驻底座包含两个独立应用：**Yaya Pet** 负责离线养成，**Yaya Chat** 用相同的芽芽像素形象进行小智对话，通过 Applications 切换。两者只共享美术，不共享游戏状态；聊天不读取或修改宠物身份、等级、金币、精神和存档。现有云端“七喜”的性格、声音与记忆配置保持不变。

## 芽芽对话

进入 Applications → Yaya Chat，准备就绪后按一次 OK 开始。沿用 0.5.3 语音服务，由服务端判断停顿，播放回答后自动继续听。短按 OK 停止；Stopped 后一次 OK 重连并开始。错误重试先回到 Ready，再确认录音。长按 OK 打开系统菜单，复用底座 Wi-Fi、设备身份和云端绑定。

房间、角色、对话卡片及倾听／思考／说话动作替换原来的声音圆球；激活码和错误详情仍按需显示。0.6.0 不改语音协议、编解码、唤醒词或 AEC。详见[语音行为与验收](docs/xiaozhi-standalone.zh_CN.md)。

## 芽芽养成

芽芽自动生活，上下键选择喂食、陪玩、休息，短按 OK 执行一次。喂食合并购买和食用，金币不足可领免费口粮。前台日常活动获得金币／经验，三级进化，两份校验存档保存成长。菜单、熄屏、切应用暂停成长与盲操作；没有离线惩罚或反复点击小游戏。

[养成说明](docs/pet-v1.zh_CN.md)定义玩法和存档。此前将宠物成长与存档接入对话的计划已取消；[应用与语音边界](docs/voice-integration.zh_CN.md)记录当前分离方式和后续扩展规则。

## 系统操作

- Wi-Fi 与电量同处顶部栏。Wi-Fi 表示获得 IP，不代表实测信号强度或互联网可达；灰色关闭、琥珀色未配置、闪动琥珀色连接中、红色错误。
- 应用区域为 **240×290，屏幕 y=30**。移除常驻 HOLD OK 底栏，收回 25 像素；素材保持原生大小，不扩大帧缓冲。
- 长按 OK 800 毫秒打开菜单，再长按返回；上下选择，短按 OK 在释放时确认。
- Settings 保留 Wi-Fi、音量、亮度、熄屏时间和熄屏模式。移除 Storage、About、设备／运行内存诊断和容量子页。构建中关闭 Bluetooth／NimBLE 与 Wi-Fi／蓝牙软件共存，忽略旧版保存的广播开关。
- Settings → Wi-Fi → Find and join network：选 2.4 GHz 网络，设备小键盘输入密码，再选 GO；不使用手机、SoftAP 或配网页面。
- 键盘支持可打印 ASCII、8–63 位密码、开放网络、删除和取消。扫描最多 12 个去重网络，手输名称最多 32 字节。连接限时 25 秒，获得 IP 后才保存；失败保留上一网络。
- 切应用保持系统 Wi-Fi，同时取消原应用的前台会话。

## 熄屏运行

默认 Pause app；Keep app running 允许已主动开启的对话继续黑屏运行。超时仍可选 0／60／120／300 秒。菜单中的 Screen off (run) 立即关闭背光，短按继续交给应用；长按 OK 亮屏进菜单。暂停模式下第一次完整按键只唤醒。菜单超时总是暂停；两种黑屏模式都暂停宠物成长。

实现为关闭背光和跳过绘制，不是深度休眠；续航收益仍需测量。

## 构建、容量和交付

目标 ESP32-C3、8 MiB Flash、无 PSRAM，使用 ESP-IDF 5.5.3，构建目录仍为 `firmware/muyu`。`./tools/validate.sh --static` 检查源码与逻辑，`--preview` 运行真实 LVGL 预览和切换检查，`--firmware` 编译并校验整包；默认 `--all` 包含三个阶段。

两个互斥前台界面共用一块 96×88 I4 角色缓冲，房间／字体只链接一次，保留 32 KiB LVGL 池及 20 行显示缓冲。设备容量页移除后，仍生成 `capacity-report.json` 供开发者查看最终链接 Flash／静态 RAM；动态堆、栈与 DMA 单独实测，最终构建前不虚报节省数值。

清单与整包流程见[新应用接入指南](docs/app-integration.zh_CN.md)。社区 BIN 会替换整套系统，不能作为插件安装。

只将校验后的 `FoloToy-AI-Passport-full.bin` 按 `0x0` 烧录，禁止全片擦除；文件须结束于 `settings@0x310000` 之前，保留 24 KiB 设置区和 `cardid@0x356000`。继续强制 3 MiB 程序上限和后续应用预留。交付绑定源码 SHA、CI、哈希和容量报告。**0.6.0 Device tests：NOT RUN**，须由用户烧录并完成[验收清单](docs/platform-acceptance.zh_CN.md)；旧版本结果不等于新镜像通过。
