# 实机验收清单

新版本 0.3.0 的 Device tests: NOT RUN。用户对 0.2.0 的功能认可不替代新镜像验收，由设备所有者烧录后记录实际结果。

1. 合并镜像按 0x0 烧录、不全片擦除；首次启动显示应用列表，没有重启循环。
2. 进入木鱼，测试上下键及短按 OK；长按 OK 打开菜单且不额外计数或响声。测试快速连按、反复长按。
3. Applications 只有自定义应用；从 Settings 进入设备状态再回木鱼，计数保留、进菜单时旧音频停止。至少菜单/恢复 100 次；以后加入第二应用后测试双向切换并记录最低堆。
4. 调整音量、亮度、熄屏时间和熄屏模式，等待两秒后重启验证保存；在应用中稳定十秒后验证恢复。由 0.2.0 不全片擦除升级，验证原联网和设置保留；上次若为 Device status 则回到应用列表。
5. 全程设备操作：搜索 2.4 GHz 网络，小键盘输入大小写、数字、符号、空格，测试删除、GO、取消；不要求手机或热点。覆盖 7/8/63 位及超长拒绝；输错不覆盖上一份网络。验证 25 秒超时、重试编辑、取消和开放网络。
6. 在线和自动重连时扫描；覆盖 12 项、同名去重、无结果、隐藏/手输名称、不支持认证。进入菜单或切换应用保持系统连接；断开/恢复路由器后自动重连、菜单响应正常。日志与截图不要公开密码或私人网络名。
7. 蓝牙广播至少开关十次，手机 BLE 扫描找到 Passport；同时开启 Wi-Fi 并敲木鱼，记录异常和最低堆。本项不测试配对。
8. 暂停模式：第一组完整按键只唤醒。继续运行模式：自动熄屏和 Screen off (run) 后木鱼按键/声音继续、屏幕不亮；长按 OK 亮屏进菜单、不额外短按。菜单超时仍暂停。未来语音应用另测黑屏录音/上传/播放，节电幅度需测电流。
9. 在启动后的十秒内连续两次断电重启，测试安全菜单；选应用稳定十秒后再重启确认恢复。该步骤测试启动中断，不是注入崩溃。
10. 后续用另一份结束于设置区之前的合格 full 镜像升级，再核验设置和最近应用仍在。未实测前不宣称已经验证跨烧录持久化。
11. Settings → Storage 与 capacity-report.json 对照：程序/应用数字一致、共享代码只算一次、未分配 Flash 与可增长程序空间分开。实际存档应反映在应用已用/系统剩余 NVS 条目。记录界面、声音、手感、联网、实际堆和串口错误；设备时序、麦克风会话、功耗与长时间运行另做专项测量。
