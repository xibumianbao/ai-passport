# 实机验收清单

Device tests: NOT RUN。由设备所有者烧录交付包后记录实际结果。

1. 合并镜像按 0x0 烧录、不全片擦除；首次启动显示应用列表，没有重启循环。
2. 进入木鱼，测试上下键及短按 OK；长按 OK 打开菜单且不额外计数或响声。测试快速连按、反复长按。
3. 切到设备状态再回木鱼；计数保留、旧音频停止。至少切换 100 次，记录 Diagnostics 最低堆。
4. 调整音量、亮度、息屏时长，两个应用共享设置；等待两秒后重启验证保存。在应用中等待十秒，重启验证恢复上次应用。
5. 手机配置 2.4 GHz 网络；获取 IP 后切换应用保持连接。断开和恢复路由器，观察自动重连及菜单响应；测试错误密码后重新配网。
6. 测试附近扫描、重复打开和取消配网、五分钟自动关闭；不要把屏幕热点密码或 Wi-Fi 密码写入公开日志。
7. 蓝牙广播至少开关十次，手机 BLE 扫描找到 Passport；同时开启 Wi-Fi 并敲木鱼，记录异常和最低堆。本项不测试配对。
8. 等待息屏，第一组按键只唤醒，不选择或敲击；确认背光不会永久关闭。
9. 在启动后的十秒内连续两次断电重启，测试安全菜单；选应用稳定十秒后再重启确认恢复。该步骤测试启动中断，不是注入崩溃。
10. 后续用另一份结束于设置区之前的合格 full 镜像升级，再核验设置和最近应用仍在。未实测前不宣称已经验证跨烧录持久化。
11. 记录界面、声音、手感、联网稳定性、实际堆与串口错误。设备时序、麦克风会话、功耗和长时间运行不能由主机测试代替。
